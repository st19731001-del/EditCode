# P2P Chat & Offline Messaging System

本アプリケーションは、WebRTC（PeerJS）を利用したリアルタイムP2P通信と、GitHub Issues APIを活用したオフラインメッセージング機能を備えた安全なカモフラージュ対応チャットツールです。

---

## 🔑 基本仕様・セキュリティ

* **表画面**: エディタ風カモフラージュ画面
* **裏画面（隠しチャット）**: メッセージ送受信・通話画面
* **アクセスコード（SECRET_PIN）**: `904900`
* **通信キー**: GitHub Personal Access Token (`ghp_...`)

---

## 📱 1. 基本的な使い方

### 隠し画面への切り替え方法
1. エディタ画面の右上にある青い **「JS」アイコンを 3回連続タップ** します。
2. 認証ダイアログが表示されたら、コード **`904900`** を入力して送信します。
3. 隠しチャット画面が表示されます。

### メッセージのマスク（非表示）解除
* 隠し画面に入った直後はメッセージがマスク表示（非表示）になっています。
* **`👁️` ボタン** をタップすることでメッセージのマスク表示/非表示を切り替えられます。

### メッセージの操作
* **コピー / リプライ / 単体削除**: メッセージを **長押し** または **左へスワイプ** します。
* **選択して削除**: 長押しメニューから **「選択して削除」** を選び、対象メッセージ（自分・相手問わず）のチェックボックスを選択してまとめて削除します。

### 表画面（エディタ）からの未読確認
* 表のエディタ画面で **`Commit Changes` ボタン** を押すと、裏で GitHub Issues から自分宛ての未読メッセージを自動取得します。
* 未読がある場合は **`Commit Changes (1)`** のように未読件数がカウントアップ表示されます。

### 自動隠蔽（安全機能）
* **傾き検知**: 端末を裏返す・傾ける（beta角 > 150° または < -150°）と、自動的に表のエディタ画面へ戻ります。
* **画面消灯・バックグラウンド切替**: スリープや別アプリへの切り替え時も自動的に表画面へ復帰します。

## 🔄 2. 端末変更・再インストール時の手順

メッセージ履歴や設定は各端末のブラウザ（`localStorage`）内にのみ保存されるため、**端末の変更時やアプリの再インストール時には以下の再設定を行ってください**。

### Step 1. 通信キー（GitHub Token）の再設定
1. 新しい端末でアプリを開き、隠し画面（PIN: `904900`）に入ります。
2. チャット入力欄に、手元に控えている **`ghp_...`**（GitHub トークン）をそのまま入力して送信します。
3. 「🔑 通信キーを保存しました！」と表示されたら設定完了です。

### Step 2. ユーザー役割（`user_a` / `user_b`）の個別設定
同一役割での同時接続を回避するため、必要に応じて役割を変更・固定します。
* **`user_a` に設定する場合**: 入力欄に **`set_a`** と入力して送信
* **`user_b` に設定する場合**: 入力欄に **`set_b`** と入力して送信

---

## ⚙️ 3. トークン発行・権限設定（トラブルシューティング）

GitHub トークンを新規発行する、または権限を確認する場合は以下のように設定してください。

1. GitHub の **Settings** ＞ **Developer settings** ＞ **Personal access tokens** ＞ **Tokens (classic)** へ移動。
2. **`repo`**（Full control of private repositories）全体にチェックを入れる。
3. 発行された `ghp_...` の文字列をアプリの入力欄に送信する。

---

## 🧹 4. 履歴の自動消去仕様

* メッセージは **既読になってから 1時間後** にローカルストレージから自動消去されます。
* 未読メッセージおよび GitHub 上の未読 Issue は消去されずそのまま保持されます。
